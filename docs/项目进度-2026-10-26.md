## 关键设计与踩坑（本轮）

1. **任务跑到一半重启服务 → 成员永远 running**  
   10:52 的 run 在 10:52:54 被重启打断；旧 `cancel_run` 只处理 `wait`，没有执行线程可中断。现在 `cancel_run` 会收尾 running 成员，`_reconcile_stale_run` 也会在 `list_runs/get_run` 时自动收尾。

2. **`-32603 / Endpoint is unavailable` 不是 ACP 坏了**  
   `rev`（`opencode-acp`）用的 `opencode/flint-40b-free` 返回 `provider.internal` 503；`impl`（`codex-node` + `deepseek-flash`）正常。现在 503 会换模型重试一次；旧代码把这种成员误标 `done` 的 bug 也修了。

3. **`Format-Table` 被当成磁盘 `format`**  
   19/50 次审批是误判；修正则后 `trust` 才真正能“非破坏性不问”。

4. **权限独立后不能回落到面板**  
   面板等级再宽也不能替工作流放行；空权限 = `ask`（fail-closed），老工作流先提示一次。

5. **审批/表单抢焦点**  
   托盘热键 + 通知不抢前台；破坏性/敏感只给工作台确认；GUI 任务仍建议先用 API/CLI，GUI 是最后手段。

6. **表单 1.5s 轮询会冲掉输入**  
   用 `COLLAB.permSig` 签名跳过重建；倒计时单独就地更新；表单提交后强制刷新。

7. **频谱空闲也烧 CPU**  
   以前常驻 ~20% 单核；现在按需 + 静音跳过 FFT + 8 秒停。

8. **音频“提示音异响”排查（非本项目代码）**  
   cocraft 没有 `winsound` / `new Audio` / 自定义提示音；唯一触发的是 `pystray icon.notify` 的 Windows 系统通知音。回环录音实测峰值 0.515、**0 削波**；系统侧 `NahimicService` / Nahimic VAD 在运行（Nahimic 是通知音爆音/破音的常见来源）。当前无 `spectrum.py` 进程，排除频谱采集。建议先停 Nahimic / 关音效增强做 A/B。

9. **Codex 的“找邮箱按钮”不是 cocraft 实现的**  
   是 agent 自己用 shell：`AppActivate` / `SetForegroundWindow` → `CopyFromScreen` → PIL 扫像素 → `mouse_event` 点击；慢且脆。这也是 `docs/桌面工具-方案.md` 的动机。

### G. `cu http`：直接调接口（`ui 0.2.75`）

用户要求「加上获取 API 的工具」。做法是**不另开一条"任意 URL + 任意头"的暗道**，而是：
只允许 http/https、写请求按动作管、cookie 复用要显式、正文不进审计。

| 项 | 落地 |
| --- | --- |
| 命令 | `cu http get --url URL [--header "K: V"] [--cookies auto|browser|none] [--timeout] [--max-bytes]` · `cu http post --url URL [--json '{...}' | --body TEXT] [--method POST|PUT|PATCH|DELETE]` |
| 权限 | `GET/HEAD` = **只读**（权限层自动放行）；`POST/PUT/PATCH/DELETE` = **动作**（默认 deny，`trust` 才允许）—— `gate.parse_cu_command` 认 `http.get` / `http.post` |
| 安全 | **只允许 http/https**（`file:` 一律拒，否则等于任意读本地文件）；响应上限 200 KB（超了 `truncated`）；4xx/5xx 也当"有响应"返回 status + body |
| cookie 复用 | `--cookies auto`（默认，有专用浏览器就用）/ `browser` / `none`；取自 **CDP `Storage.getCookies`**，按域名 + 路径 + Secure 过滤；结果里回 `cookies_used` 告诉 agent 用了哪些 |
| 代理 | **本机**走 `netsafe.local_urlopen`（绕系统代理，踩坑 #45）；**外网**走系统代理 + 合并 CA |
| 审计 | `http_get` / `http_post`，只记 **method / url / status / 字节数 / 用到的 cookie 名**，**正文不进链** |
| 工具目录 | 加进「执行与取数」（现在 3 个：`browser.eval` + `http.get` + `http.post`），面板自动显示，无需改前端 |
| 回归 | 新增 `tools/http_test.py` **25 项**（本地服务：GET JSON / 文本 / 截断 / 4xx / `file:` 拒绝 / 写请求默认拒 / `--json` body 与 Content-Type / `--method PUT` / 非法 JSON 报错 / `--header` / **cookie 复用**（真起无头 Edge 塞 cookie）/ 审计无正文） |
| 数字 | `check_features` **2154 项 / 缺失 0**；`run_suite` **47 套** |
