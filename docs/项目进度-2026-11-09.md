## 4. 关键决策（拍过的板）

1. **定位**：从"数据不出机"改为 **"明文不出机"** —— 团队版可以出密文（密钥在客户手里），中继只存密文；
2. **团队版接入**：不要求客户"搭内网"，只要一个共享目录 / 一台团队节点 / （可选）密文中继；
3. **策划会话**：**一个会话 = 一个项目**（`projectKey` 创建后不可变）；切项目 = **点另一个策划会话**，不是改绑定；
4. **换策划 agent**：走 `HANDOFF.md` + 能力复核，不靠旧进程状态；
5. **并行隔离 v1 边界**：子目录仓库退回影子副本、超限/单成员不隔离、**不自动合并**。
