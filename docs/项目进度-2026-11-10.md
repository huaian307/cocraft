### 2.1 主控面板现在的形态

```
[工作流左栏]  [工作流画布]  [主控会话右侧面板]
                              ├ 标题/状态 · ? · ×
                              ├ 一行摘要：N 阶段 · M 成员 · 校验 · 提醒 · 运行
                              ├ [校验并确认] [开始执行/取消运行] [刷新] [更多 ▾]
                              └ 对话列表 + 输入框
```

- 有绑定聊天 → 面板内直接发到该聊天；没有 → 自动建「策划 · …」、`/planner/bind`、把 `planner/resume` 的接棒上下文 + 需求合成第一条；**发送后不离开面板**
- 「更多」：完成报告 / 重试·重规划 / 隔离·应用改动 / 写交接 / 换策划 agent / 删除会话
- 计划由主控 agent 维护；**不需要手改 Plan JSON**（旧面板里作为「高级」折叠项保留）

## 4. 关键决策（本轮拍板）

1. **主控会话不是左侧聊天列表的一项**：它属于工作流面板（左栏记录 + 右侧面板）；绑定的普通聊天才出现在聊天列表。
2. **主控会话与画布同屏**：用右侧面板（不弹层、不跳会话），画布自动让位。

5. 旧策划面板保留为「高级」入口（工具菜单），供直接编辑 Plan JSON / 查看完整信息。

### 8.2 为什么删主题是"改 CSS 底盘"而不是"删一个选项"

`hiru` 不是并列的第二套主题 —— 它**就是 `:root`**（原浅色调色板），`[data-theme="chapel"]` 才是覆盖。
所以删它必须把 `:root` 换成 chapel 的色值，否则：

- 首屏（JS 还没跑）会闪一下浅色；
- 用户主题（`data-theme-user` 叠加）的底盘会变成浅色，社区深色主题会花。

顺带删掉的：`[data-theme="hiru"] #sidebar/#topbar/#composer` 的纸白毛玻璃兜底、
`html[data-theme="hiru"].has-live .lb-wash { display:none }`、
设置里的「和纸白昼」卡片与 `#theme-hint` 一次性提示条。

**兼容**：老浏览器 `localStorage["cocraft.theme"] === "hiru"` → `normThemeId()` 归一成 `chapel`，
不弹提示、不留残影；`backend/themes.py` 的 `RESERVED` 仍占着 `hiru`/`yoru`，防止社区主题撞名。

### 8.4 三个真 bug（都记进 `docs/BUILD.md` §9）

1. **安装包"文件已损坏"**：上一版 ISCC 编译被我给的 120s 超时**中途杀掉**，只剩 52 MB 半截 exe（payload 826 MB）→ 安装时报 `The setup files are corrupted`。**别给 ISCC 设短超时**，正常产物 ~200 MB。
2. **删 JS 不等于删功能**：只删 `40-music.js` 会让 `02-shell` / `11-engine` / `41-visual` / `app.js` 里 44 处调用变成 `syncLyricsVisibility is not defined`（用户实测报错）。必须留同名桩。
3. **重复 `const` 会整份 SyntaxError**：桩里写了 `const MUS`，而它本就在 `41-visual.js` —— 顶层 `const` 跨 script 共享，重复声明让**整个 `41-visual.js` 不执行**，表现成 `initWallpaperPicker is not defined`。自查手法：把 index.html 里所有 script 按顺序拼成一个文件，用随包 node `--check`。

顺带修的：`packaging/build.py` 的 `drop_tree()` 用了 `time.sleep()` 却**没 `import time`**（被占用时不是重试而是 `NameError` 崩）；
`cleanup.py` 子进程没给 encoding（读线程抛 `UnicodeDecodeError`，日志全是噪声）；
`isolation.py` 的 `_git apply -` 实际没把补丁喂给 stdin（临时文件兜底可用，但多一次 I/O）；
`planner.py` 角色缺省值 `implement` 与全局规范 `implementer` 不一致。
