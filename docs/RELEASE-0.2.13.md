# cocraft 0.2.13 — 多智能体协作台：工作流画布 + 节点级权限

> Windows 10/11 · x64 · 单机 · 本地优先（数据不出机）

这是 `v0.1.62` 之后积压的一大批能力收口，主线是**「一套流程可以保存、复用、再跑」**，
以及**「权限不必一刀切」**：每个 agent 成员可以有自己的权限等级，破坏性操作仍然必须你确认。

## 这次有哪些新东西

### 1. 本地协作工作台（0.2.1 ~ 0.2.9）
- 顶栏「协作」→ 全页工作台，**不登录、不上云**；每个成员一个独立的 agent 进程，可并行跑多个任务。
- 每个成员一列（Markdown / tokens / 上下文 / 工具活动）；提交前逐条审批；可取消单个 / 全部、重跑、导出审计 JSON。
- 多方案**对比**（正好 2 人时逐行差异）、**仲裁**（审查者收口「结论：推荐 X」，可点跳列）。
- 运行历史：项目徽章 + 按项目筛选 + 删除记录 + 多任务并行。

### 2. 工作流画布（0.2.11）
- 一套流程（成员 / 角色 / 大脑 / 目录 / 默认任务）存成**工作流**，下次一键再跑。
- 左栏 **项目 → 工作流 → 运行**；工作流可 ▶ 一键跑，运行历史可按工作流筛。
- 画布：任务节点 + 成员节点 + reviewer 连线；拖动排版、滚轮缩放、平移、适应窗口、双击加成员。
- 检查器：点节点改角色 / 名字 / 大脑 / 权限 / 默认任务；快速任务条 Enter 直接开跑。
- 运行详情默认**只看选中的节点**，点「⊞ 并排」才铺开全部。

### 3. 节点级权限（0.2.13）★
- 每个成员可单独设：跟随面板 / 全部询问 / 只读自动 / 读写自动 / 执行自动 / **信任（非破坏性自动）**。
- **信任 = 读 / 写 / 执行 / 联网不再逐条问；删除、格式化、关机等破坏性操作仍然必须你确认**（放行前仍先进隔离区）。
- 保存进工作流（下次继承）；运行中也能改（新 `POST /orchestrate/member`），下一条申请立刻按新等级判。
- 权限面板从窄横条改成**右侧 620px 抽屉**：成员权限、待批卡片（命令原文）、审批历史一屏处理。
- 修好了工作台里的 `codex-node`「看起来没有联网 / 不会干活」：不再被 Codex 自己的 `codex-auto-review` 拦死，改为走 ACP 逐条权限申请。

### 4. 对话与体验（0.2.2 ~ 0.2.10）
- **消息导航**：回到底部、问题列表、上一问 / 下一问（`Alt+↑/↓`）、回到本问。
- **ACP 中途补充要求**：一轮跑着时发消息会排队（不再 409），本轮结束自动投递；「已排队 / 未送达」可见。
- **上下文估算**：只给 prompt usage 的 agent 也显示「上下文 ~N」。
- **接续列表分组**：群聊 AI 成员 / 本地协作的内部会话收进第二个标签，不再混进项目会话。
- **运行历史删除 + 多任务并行**。

### 5. 安全与修复
- `0.2.3` agent 安全兜底：dsh 的「永不问」模式不会再悄悄回到 `danger-full-access`（三层兜底 + agentlist 红字）。
- `0.2.7` **跨引擎模型引用修复**：切引擎后模型清单立刻作废并重拉；绝不把 `providerID:"acp"` 写进 OpenCode；归一失败不写、只提示。
- `0.2.8` 信任面板收尾：群聊审批时间线落盘、可撤销列表、agent 活动、派活 / 仲裁结论。
- `0.2.12` 入口收口：删除一次性「新建任务」，**工作流是唯一入口**。

## 升级方式

- 已安装 `v0.1.62` 或更早：下载本安装包**覆盖安装**即可；`runtime\`（设置 / 会话 / Key / 主题）保留。
- 安装新版后，设置 →「软件更新」可继续一键更新。
- 首次启动会要求选择引擎 / agent；模型 Key 可在向导里填，也可稍后在设置里补。

## 已知限制（请先看）

- 仅 **Windows 10/11 x64**、单机、单用户。
- **执行模型仍是"扇出"**：一个任务并行派给 N 个成员；画布是编辑器 + 启动器，**串行阶段 / 条件分支还没做**（P4）。
- **可逆执行是尽力而为**：只保得住能识别出的目标；codex 不报路径、猜不出时会如实说"这次没能预先隔离"。
- **破坏性操作永远需要确认**（即使成员权限设成「信任」）。
- 部分 ACP agent 不主动上报上下文用量 / 权限路径，界面会标注「—」或「不支持」。
- 群聊 / 音乐使用非官方接口，随时可能变化；仅供个人使用。
- 安装包未签名，Windows 可能提示"未知发布者"；请核对下方 SHA256。
