# cocraft 0.2.0 — 敢让 AI 动你电脑，因为每一步都可见、可管、可撤回

> Windows 10/11 · x64 · 单机 · 本地优先（数据不出机）

这是 `v0.1.62` 之后积压能力的一次收口。**重点不是多了几个按钮，而是把"AI 在你电脑上干活"变成一条可检查、可撤回的流程。**

## 这次有哪些新东西

### 1. 可逆执行（安全网）
- **破坏性命令先隔离再放行**：确认后、执行前，目标先复制进 `runtime/quarantine/`。
- **撤销这一轮**：每轮快照 → 列出改/增/删/改名 + 行级 diff → 一键退回；
  撤销"新增"前会先自动隔离，**撤销本身也可逆**。
- 工具菜单里可看隔离区、恢复文件、清理旧快照。

### 2. 多智能体主动编排
- **角色**：实现者 / 审查者 / 测试者 / 调研者（只注入本人提示词）。
- **派活**：多选成员 → 一条 `@a @b 任务` → 各自**并行**干；末尾有「派活 · N/M 已回复」卡。
- **对比**：每人一列并排；正好 2 人时给逐行差异。
- **仲裁**：请审查者收口「结论：推荐 X」，结论**可点跳列**并记入历史。
- **一键建组**：3 个预设，一次建好、自动进群、开应答；预设可自定义；建完可自动派第一活。
- **文件改动**：对比时每列显示"这个人改了哪些文件"（文件级，不占磁盘）。

### 3. 信任面板（输入框「权限 ▾ → 信任面板…」）
- 权限 **5 档**集中展示 + 一键切换；放宽到「执行 / 全部放行」要二次确认，另有「立即收紧」。
- **待批准**：当前会话 + 群聊；「去处理 / 去群聊处理」。
- **最近「始终允许」**：逐条撤销或清空全部（只影响当前 agent）。

### 4. 上下文余量
- 输入框左下角「**上下文 剩 X%**」：
  - OpenCode：模型窗口上限 + 上一条回答的 tokens；
  - ACP（codex / opencode-acp 等）：agent 上报的 `usage_update`；
  - 拿不到就不编数字，并说明原因；≥80% 金 / ≥95% 红。

### 5. 安装与 agent
- agent 组件改为**可选**（node 跟着适配器装）；覆盖安装保留设置与会话，可随时补装。
- 面板内可直接 npm 安装常见适配器（codex / claude / opencode），自动识别入口并注册。

### 6. 修复
- 权限等级切换"看起来生效、其实没写进去"（POST body 未序列化）。
- 在 OpenCode 客户端删掉的会话，不再残留在 ACP 列表。
- 保存模型 API Key 后看不到"已保存 + 掩码"提示。
- 上下文压缩 / shell / 模式切换 / 模型切换消息不再显示"未知结构"。
- 群聊 `☰` 菜单重排，不再裁掉「大脑」下拉与「＋ 建」。

## 升级方式

- 已安装 `v0.1.62` 或更早：下载本安装包**覆盖安装**即可；`runtime\`（设置 / 会话 / Key / 主题）保留。
- 安装新版后，设置 →「软件更新」可继续一键更新。
- 首次启动会要求选择引擎 / agent；模型 Key 可在向导里填，也可稍后在设置里补。

## 已知限制（请先看）

- 仅 **Windows 10/11 x64**、单机、单用户。
- **可逆执行是尽力而为**：只保得住能识别出的目标；codex 不报路径、猜不出时会在群里**如实说"这次没能预先隔离"**。
- 破坏性操作**永远需要确认**；`all` 档连工作区外也放行（破坏性仍确认）。
- 部分 ACP agent 不主动上报上下文用量 / 权限路径，界面会标注「—」或「不支持」。
- 群聊 / 音乐使用非官方接口，随时可能变化；仅供个人使用。
- 安装包若未签名，Windows 可能提示"未知发布者"；请核对下方 SHA256。
