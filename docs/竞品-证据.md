## 1. 直接竞品（Windows 原生 · 已核实）

### AgentMux

| 项 | 内容 |
| --- | --- |
| 平台 | **Windows x64（主开发平台）**、macOS（Apple Silicon）、Linux（x86_64） |
| 许可证 / 价格 | Apache 2.0，免费开源 |
| 形态 | Rust + CEF + SolidJS 桌面应用；Windows 有 **Microsoft Store 签名版**、`.exe`、便携 `.7z` |
| 关键能力 | 19 种 harness（Claude Code / Codex / Gemini / OpenCode / DeepSeek Harness / Cline / goose / Aider…），其中多种走 **ACP 长连接**；Swarm 树（含 subagents / todos / 工具）；**Drone = 可视化 DAG**；Kanban；**Audit 面板**；Vault（密钥按名使用）；Agent 间消息（MuxBus）；定时任务；本地优先、无遥测 |
| 来源 | <https://agentmux.ai/> · <https://docs.agentmux.ai/getting-started/> · <https://github.com/agentmuxai/agentmux> |
| 对我们的含义 | **最强的直接竞品**。它的"多 agent 工作台"成熟度高于我们；我们**不能**再用"Windows 上没有多 agent 工作台"做卖点 |

## 2. 我们仍然独有的（截至 2026-11-03，公开资料 + 本机实现）

| 能力 | 竞品现状 | 我们的实现 | 证据强度 |
| --- | --- | --- | --- |
| **不挑目录**（无 git 也能回滚） | AgentMux / Nimbalyst / Volt / Kepler 的隔离与回滚主要建在 **git worktree / git ref** 上 | `backend/snapshots.py`：自己扫盘 + 内容寻址仓，不依赖 git | 强（代码 + `quarantine_test` 62 项） |
| **删除前复制**（不是删完再捞） | 公开文档未见等价的"命中删除命令 → 先拷进隔离区 → 再放行" | `quarantine_before_allow` + `file_rank` 低风险删除自动隔离 | 强（代码 + `low_risk_delete_test` 16 项） |
| **可验证审计** | AgentMux 有 Audit 面板；Kepler 有 Agent Graph；**公开文档未见哈希链 + 离线复核 + 签名** | `backend/audit.py`：append-only JSONL + `seq/prev/hash` + 归档 + CSV/MD 导出 + `ssh-keygen -Y sign` | 强（`audit_chain_test` 106 项 + 独立校验脚本） |
| **跨厂商 fail-closed 权限** | 各家都有审批；少见"范围未知一律问 + 成员级上限 + 破坏性默认不放行"写成硬规则 | 5 档权限 + `allowed_by_level` + `permLevel` 上限 + 审批队列 | 中强（代码 + 回归） |
| **诚实语义** | 多数工具默认"成功" | 保不住明确说"没保住"、`skipped` 如实记录 | 中（设计选择，难以被竞品复制的是文化） |

## 5. 对照实验（下一步，比功能表有说服力）

同一台 Windows、同一个普通目录（**故意不是 git 仓库**）、同一个任务：

```text
建一个 dist/ 目录（里面有 3 个文件），然后执行：
Remove-Item -Recurse -Force .\dist
```

记录四件事：

| 指标 | 怎么记 |
| --- | --- |
| 有没有**弹审批** | 截图 / 日志 |
| 有没有**先复制** | 看是否出现隔离目录 / 备份 |
| 删完能不能**一键恢复** | 找 UI 里的 restore / undo |
| 有没有**可离线复核的记录** | 导出 / 看哈希 |

对照：cocraft / AgentMux / Nimbalyst / Volt / Kepler。
结果写回本文件 §1 对应产品行，并更新 `docs/竞品与定位.md`。
