## 关键设计与踩过的坑（本轮的"下次别再犯"）

1. **判断"用户当前用哪张壁纸"就别说猜**：直接读
   `…\wallpaper_engine\config.json` → `TWG.general.wallpaperconfig.selectedwallpapers.<Monitor>.file`。
   （我先猜了 WE 列表里另一张，被用户当场纠正。）
2. **别用 `data:` URL 测视频能不能播**：Chromium 会误报 `MEDIA_ERR_SRC_NOT_SUPPORTED(4)`。
   要用**同源静态 URL 直接导航**再读 `videoWidth` / 截图。
3. **WebGL 画布"暂停那帧"会黑**：绘制缓冲合成后清空。展开侧栏时正确做法是
   **同帧 `drawImage` 抓进 2D 定格层（`.lb-freeze`）再 `pause()`**，抓不到就退回静态图。
4. **document 捕获阶段先于 window 冒泡**：新做"拖拽接收区"必须用它 + `stopPropagation`，
   否则会被聊天的 window drop 抢走（已写进 AGENTS.md 的壁纸章节）。
5. **`builtin:` 前缀**：官方壁纸既不在 `runtime/wallpapers`、也不在 WE 目录，
   靠 `_wallpaper_entry()` 的 `builtin:` / `custom:` 分支统一解析；删除接口对 `builtin:` 直接 400。
6. **GitHub 单文件 100 MB 限制**：124 MB 的 WE 视频不能进 git（因此那版被放弃）；
   现在这份 2.8 MB 才可以，`.gitignore` 里是**逐文件放行**而不是通配放行。
