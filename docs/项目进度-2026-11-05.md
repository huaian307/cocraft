## 3. 当前能力总览

### 3.1 会话与引擎
- 单聊 / ACP 多 agent / agent 会话导入接续。
- 三类会话隔离：
  - 单聊：左侧会话列表
  - 工作流成员：工作流「成员会话」
  - 群聊 AI 成员：群聊「AI 会话」
- `session_scope.py` 扫描内部会话 id，`GET /session/managed` 供单聊列表过滤。
- 工作流成员会话：`runtime/state/_orchestrator/runs/<run>/<member>.sessions.json`。
- 群聊桥会话：`runtime/state/_cocraft_bridge_sessions.json`。
- 工作流「继续上次」复制上一轮成员会话文件；旧 run 不被污染；匹配不到 / 换引擎 / agent 不支持 resume → 新建。

### 3.2 多 agent 工作流
- 工作流 = 可复用实体（成员 / 阶段 / 默认任务 / 权限 / 项目目录 / 画布）。
- 阶段串行、阶段内并行；条件 / 失败策略 / 重试。
- 项目级画布：`_collab_workflows.json` 的 `projects[<cwd>].canvas`，同一项目共享坐标。
- 工作流运行记录、成员活动、逐行差异、仲裁、待批权限、表单追问。
- 工作流成员独立 `AcpService` + 独立会话文件。

### 3.3 可逆执行 / 忏悔室
- 破坏性 / 修改操作放行前自动留存旧版。
- 单文件回滚到指定版本；回滚前备份当前文件。
- 时间保留期仅用于低风险删除；修改前旧版不再按时间自动清，而是按 git 提交出清。
- git 出清只清「提交前 + 旧内容在 git 对象库」的记录；未跟踪 / 未提交保留。
- 墓碑（超 64MB 可再生文件）只记清单，不能回滚。

### 3.4 安全 / 权限
- 五档权限：`ask / read / edit / exec / all`；工作流成员另有 `trust`。
- 破坏性操作永不自动放行；低风险删除是唯一「先隔离再自动」例外。
- 群聊成员权限上限只紧不松：`min(面板等级, 成员上限)`。
- 敏感读取、提权窗口、危险词仍有独立闸门。
- 本地接口无鉴权仍是已知风险。

### 3.5 其他
- 文件查看：文本 / 图片 / PDF / 音视频预览；Markdown / HTML 沙箱；生成文件按意图自动代开。
- 审计链：append-only + 哈希链 + CSV / JSON / 报告 / 人话简报 / 签名校验。
- 主题 / 壁纸：chapel 默认 + hiru；视频 / 场景 / 静态；官方内置壁纸。
- 音乐 / 歌词 / 频谱 / 面板终端 / 文件树 / cu 桌面与浏览器工具。

## 6. 当前边界与风险

1. **未打包 / 未签名**：线上仍是 `v0.2.62`；本轮改动未生成新安装包。
2. **运行历史没有自动清理**：`KEEP_RUNS = 60` 目前没有真正接入清理；run 目录 / 成员会话会长期保留，需要手动删或后续做保留策略。
3. **工作流会话管理只列元信息**：标题 / 成员 / 运行 / 消息数 / id；还没有「打开完整成员会话」的只读查看器。
4. **项目画布仍是单层高亮**：切工作流保留坐标，但同一时刻只渲染当前工作流；其他层节点坐标保留，未做“显示全部图层”。
5. **git 出清是保守策略**：未跟踪 / 未提交的旧内容不会自动清；如果希望彻底只按 git，需要额外确认是否接受丢失未跟踪旧版。
6. **Agent 自己的客户端仍可能看到内部会话**：面板做了单聊过滤，但 OpenCode / Codex 等 agent 自己的会话列表是它们的数据，不在面板控制内。
7. **审批绕过**：完全绕过审批的 agent 模式不会触发自动留存；需要「每轮工作区快照 + 带内容」兜底。
8. **本地接口无鉴权** 仍是架构级风险；有 shell 的 agent 理论上能改动本机状态。
9. **LICENSE / 第三方声明** 尚未落地。
10. **AGENTS.md / docs/PROGRESS.md 不进 Git**：当前工作树仍有多天未提交改动，发布前需要整理。

## 7. 建议的下一步（按优先级）

1. **打包 + VM 验证 + 发布**（用户明确要求时再做）：`packaging/build.py` → 覆盖安装 → 干净机安装 → 版本 / Key / 主题 / 壁纸保留。
2. **运行历史保留 / 清理**：按项目保留最近 N 轮；只清会话文件，不删审计；提供「清理旧运行」预览。
3. **成员会话只读查看器**：工作流 / 群聊管理列表点进去看完整消息；复用现有会话渲染，不启动 agent。
4. **项目画布所有图层视图**：给节点加工作流前缀 / 泳道；「只看当前」与「显示全部」切换。
5. **git 出清策略确认**：是否允许清理未跟踪旧内容；是否按项目/时间/容量加二级出清。
6. **LICENSE + 第三方声明**、安装包签名。
7. **技能 / 工作流沉淀**：一次 run → 可复用 `SKILL.md`（人审后启用）。
