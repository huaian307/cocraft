# 官方主题 · 礼拜堂（chapel）设计与实施方案

> 状态：**已落地（`ui 0.2.47`~`0.2.48`）** —— 决策与实现情况见文末「§10 已拍板与落地」
> 相关：`docs/THEMES.md`（主题包契约 / 底盘+叠加模型）、`AGENTS.md`「主题与素材」
> 视觉参照：官方背景壁纸 `frontend/assets/hiru-bg.jpg`（**白袍兜帽修女 + 金线刺绣 + 手持蜡烛**，暗底、暖烛光、余烬飞散）

---

## 0. 一句话

把壁纸里那个「**白袍 · 金线 · 烛光**」的修女气质，变成一套**深色礼拜堂**皮肤：
暖黑石墙底、米白文字（白袍）、金色镶边（刺绣）、烛焰橙（火）做焦点色，
弹窗头顶一道**尖拱**、边缘一线**金线**，其余一切克制 —— 不喧哗，像晚祷。

---

## 1. 定位与观感

| 维度 | 取法 | 依据（都来自壁纸） |
| --- | --- | --- |
| 明暗 | **暗色专属**（`mode: dark`） | 壁纸本身就是暗底 + 烛光，浅色会让文字和画面打架 |
| 材质 | 暖黑**磨砂玻璃**（沿用现有 `html.glass`，只换参数） | 壁纸是柔焦油画质感，玻璃能透出烛光 |
| 主色 | **烛焰橙金** `#e0a24a`（焦点 / 主按钮 / 选中） | 画面里唯一的高饱和光源 |
| 辅色 | **绣线金** `#d9bd83`（描边 / 标签 / 分隔） | 兜帽与肩章的金线刺绣 |
| 点缀色 | **彩窗红** `#c56a55`（极小面积：当前档、@我、徽章） | 哥特彩窗的暖红；不大面积用，避免"红配金"土豪感 |
| 文字 | **米白** `#f6efe3`（白袍） / 次级 `#cdbfa9` / 弱 `#9c8d79` | 白袍 + 阴影层次 |
| 危险 | 红 `#e0645c` / 填充按钮 `#c94a44` | **安全语义不能被主题弱化**（铁律） |
| 圆角 | 6px（比 hiru 的 3px 略软，仍偏硬朗） | 石造建筑的转角 |

**不做**：不加背景音乐、不加音效、不做彩色玻璃整屏底纹、不换字体文件（不联网、不引二创素材）。

## 2. 配色（直接对到现有 CSS 变量）

### 2.1 实色变量（`[data-theme="chapel"]` 块）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#17120f` | 玻璃关掉时的实底（暖黑，不是纯黑） |
| `--paper-2` | `#201a15` | 第二层纸面 |
| `--paper-3` | `#2a221b` | 第三层 / 输入框 |
| `--ink` | `#f6efe3` | 正文（白袍米白） |
| `--ink-dim` | `#cdbfa9` | 次文本 |
| `--ink-faint` | `#9c8d79` | 弱提示 / 占位 |
| `--hi` | `#e0a24a` | 主强调（烛焰） |
| `--hi-deep` | `#a86c22` | 主强调深色（按下 / 边缘） |
| `--hi-wash` | `rgba(224,162,74,.16)` | 选中底晕 |
| `--gold` | `#d9bd83` | 金线 / 徽章 |
| `--gold-soft` | `#f0dcae` | 金线高光 |
| `--sakura` | `#c56a55` | 彩窗红（点缀） |
| `--line` | `rgba(246,239,227,.16)` | 分隔线 |
| `--line-soft` | `rgba(246,239,227,.08)` | 细线 |
| `--ok` | `#63a97f` | 完成（偏暖的绿，别刺眼） |
| `--run` | `#d9bd83` | 进行中（金） |
| `--err` | `#e0645c` | 失败 / 拒绝 |
| `--radius` | `6px` | 圆角 |
| `--shadow` | `0 14px 38px rgba(0,0,0,.42)` | 悬浮阴影（暗底要更重） |

### 2.2 玻璃参数（`08-visual.css` 的那套）

| 变量 | hiru（现状） | chapel（新） | 说明 |
| --- | --- | --- | --- |
| `--g-tint` | `128,128,128` | `30,24,19` | 暖棕黑 tint |
| `--g-a1` | `0` | `.38` | 主面略填色（暗底上要"比背景亮一点点"才有面） |
| `--g-a2` | `.05` | `.26` | 第二层 |
| `--g-a3` | `.04` | `.20` | 第三层 |
| `--g-scrim` | `rgba(8,8,10,.52)` | `rgba(12,9,7,.58)` | 区块暗底（更暖） |
| `--g-edge` | `rgba(255,255,255,.30)` | `rgba(232,200,150,.18)` | **金色 hairline**（刺绣边） |
| `--g-top` | `transparent` | `rgba(255,214,150,.10)` | 顶部一道烛光"汗光" |

⚠ `--g-blur` 仍由设置里的「模糊程度」控制，主题**不许**动它（用户滑到 0 就该全透明）。

### 2.3 对比度预算（先算，交付时再实测复核）

| 组合 | 近似对比度 | 结论 |
| --- | --- | --- |
| `--ink` on `--paper` | **15.9 : 1** | 正文充裕 |
| `--ink-dim` on `--paper` | **9.9 : 1** | 次级充裕 |
| `--hi` 作文字 on `--paper` | **8.7 : 1** | 强调文字可用 |
| 主按钮（深底字 `#1b1410` on 烛金渐变） | **8.6 : 1** | 按钮可读 |
| 危险文字 `#e0645c` on `--paper` | **4.7 : 1** | 小字号偏紧 → 破坏性小字改用 `#ff8f88`（≈7:1） |
| 危险按钮（白字 on `#c94a44`） | **5.4 : 1** | 达标 |

## 3. 组件与"签名细节"（克制：只加 5 处）

| # | 位置 | 做法 | 为什么值得加 |
| --- | --- | --- | --- |
| ① | **顶部条底边** | 1px 渐隐金线（左右淡出）+ 悬停微亮 0.4s | 祭坛边缘的一线金；不动布局 |
| ② | **弹窗头部** | 顶部两角用 `clip-path` 做**极浅尖拱**（半径 ~14px 的弧），标题旁校徽换成新 inline symbol `#mk-chapel`（尖拱窗 + 烛焰，单色描边） | 一眼认出"这是礼拜堂主题" |
| ③ | **助手气泡** | 左上角 6px 径向高光点（烛焰），`opacity .5`，仅 chapel | 呼应壁纸里唯一的光源 |
| ④ | **选中 / 当前档** | 左侧 2px 金线 + `--hi-wash` 底晕（替代 hiru 的绯红高亮） | 列表里"选中的那一条"更清楚 |
| ⑤ | **滚动条 / 滑块 thumb** | 烛金→深金竖渐变（沿用 `--hi`/`--hi-deep`） | 细节统一，零成本 |

**校徽**：`index.html` 里加一个 `<symbol id="mk-chapel">`（尖拱窗 + 中间一点火焰），只在 chapel 下 `use` 它。
（不删 `#mk-tree`，hiru 还要用。）

**粒子**（现有「金色光点」/「绿色竹叶」两个开关）：
chapel 下**默认**把金色光点当"余烬"（更小更慢：尺寸 ×0.7、速度 ×0.6、色 `#e6a548`），竹叶默认关。
**只改默认值**，用户在「壁纸与外观 → 粒子」里手动开的优先级更高。

## 4. 背景

| 层 | 方案 |
| --- | --- |
| 静态 | 新增 `#static-bg` 的 `<div class="sb" data-bg="chapel">`，图仍是**官方壁纸 `hiru-bg.jpg`**（项目自有资产），套 `filter: brightness(.88) saturate(1.06)` + `::after` 底部中心一团 ≤10% 的暖光 + 四角暗角（纯 CSS，不新增图片） |
| 动态 | 不新增素材：继续用官方内置动态壁纸 `builtin:official`（烛光 10s），chapel 只是"把静态背景换成暗调版" |
| 亮度 / 模糊 | 仍由设置里的滑块控制（`--bg-dim` / `--g-blur`），主题不抢 |

> 备选（若滤镜在低端机掉帧）：用脚本从 `hiru-bg.jpg` 生成一张 `chapel-bg.jpg`（暗角+暖调烘焙进去），
> 好处是零运行时滤镜；坏处是多 200 KB 素材。**先做 CSS 版，实测掉帧再换。**

## 5. 交付形态（要你拍板）

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| **A. 内置底盘主题（推荐）** | `<html data-theme="chapel">`，与 `hiru` 平级；设置里加"主题"两卡片（hiru / chapel），默认仍 hiru | 真·官方主题；切换立即生效；不受用户主题安装影响；安装包自带 | 要动 `themes.py` 的 `BUILTIN` / `_is_builtin`、`applyTheme()`、CSS 变量块、背景槽、切换 UI、回归 |
| B. 用户主题包 | `runtime/themes/chapel/`（`theme.json` + `theme.css` + `preview.png`），随包预装、也能上架工坊 | 零改动底盘机制，风险最低；符合 `docs/THEMES.md` | 只是"叠加"：`data-theme` 仍 hiru，深色要靠 CSS 全面覆盖，边界模糊；列表里显示为"已安装"而非内置 |
| C. 两者都做 | A 的样式写成一份可导出的 `theme.css`，再打一个工坊包 | 生态友好（别人能装同一个主题） | 多一步打包与同步维护 |

**我建议 A**，并且**把变量/签名样式写成独立一节**，将来 C 的工坊包直接复用（几乎零成本）。

## 8. 风险与边界

1. **`themes.py` 只认 hiru**：`_is_builtin()` / `read_active()` 现在会把其它 id 回落成 hiru → 不改就"存了等于没存"。
2. **`applyTheme()` 目前忽略入参**（恒 hiru）：要改成真切换，并负责清理用户主题的叠加（`data-theme-user`、`#cocraft-theme`、`data-ico-on`）。
3. **别抄 hiru 的 22 处 `[data-theme=...]`**：新模式只需要"变量块 + 5 处签名"，抄规则会埋下"改一处漏一处"的坑（`yoru` 已删干净，别借尸还魂）。
4. **安全色语义**：破坏性/拒绝永远红，且小字号用更亮的红；主题不许把危险色染成金色。
5. **玻璃与模糊耦合**：只改 tint/alpha/edge，不动 `--g-blur`。
6. **版权**：背景仍用官方自有资产；不引二创图；预览图用自家截图。

## 10. 已拍板与落地（2026-10-25）

### 10.1 你拍的板

| 项 | 决定 |
| --- | --- |
| 名字 | **圣烛教堂**（id `chapel`） |
| 明暗 | **只做暗色**（不做「白袍日间」浅色变体） |

| 范围 | **包含各个按钮**（主按钮 / 危险按钮 / 图标按钮 / 滑块 / 标签 / 选中态） |

### 10.2 落地情况

### 10.3 与方案不同的地方（都是实测后改的）

1. **老用户提示从"顶部横幅"改成"侧栏提示条"**：顶部横幅是**单槽**，启动时会被"已连接 / 更新"这类提示顶掉（测试里也复现了）；
   侧栏条能一直挂着直到点掉，且不挡消息区。
2. **主按钮文字改成深色**（方案里就写了，实测确认必须）：白字压烛金只有 ~2:1；深棕字 `#1b1410` ≈ 8.6:1。
3. **顶栏危险按钮要单独压红**：`#topbar .actions button` 带 id（1,1,1），会把 `.danger` 的红色盖掉 → 暂停键必须单独一条规则。
4. **消息气泡要单独加厚**：气泡底色是 `--paper`（38% 暖黑 + 28px 模糊），叠在壁纸亮部（白袍 / 烛光）上会糊成**浅灰白纱**、白字读不清
   → chapel 下气泡单独到 `rgba(22,16,12,.72)`（这是用户看图后报「不要这层白色的蒙版」的直接原因）。
5. **全屏那张白纱必须换掉**：`#live-bg .lb-wash` 是给浅色主题写的 `rgba(250,247,242,.34~.58)` 白纱，
   `z-index:3` 盖在整屏视频上，以前只有 hiru 会隐藏它 → chapel 下壁纸整体发灰白（气泡/面板一起发灰）。
   现在 chapel 换成暖黑暗纱 `.30/.22/.50`（与静态背景槽同值）。
6. **没做**：浅色「白袍日间」变体（按决定砍掉）、图标槽换教堂风 SVG（用"按钮样式"覆盖，不改字形，避免认不出工具）、工坊包（A 方案已足够，暂不导出）。
