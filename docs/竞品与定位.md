## 1. 一句话切割

> 别人卖"**把文件找回来**"（赌磁盘残片还在）；
> 我们卖"**证明这次动作是谁、凭什么、能不能退，并且退得回来**"（事前留底 + 每步入链）。

**这两句不是营销话术，是技术事实**：恢复软件在**删之后**去捞残片；我们在**删之前**先复制（隔离区）+ 每轮落内容寻址快照。

## 2. 四层竞品地图（别混着比）

| 层 | 代表 | 它解决什么 | 它的盲区 | 价格感知 |
| --- | --- | --- | --- | --- |
| **① 回收站** | Windows 回收站 / Mac 废纸篓 | 资源管理器里删的文件 | **`del` / `Remove-Item` / `rm` 不进回收站** —— 而这正是 agent 最常干的事；改文件也不进 | 免费 |
| **② 系统快照 / 备份** | Windows VSS（卷影副本/还原点）、文件历史、OneDrive 版本；mac **Time Machine**、**APFS 本地快照**、Versions、iCloud 版本 | 整机/整盘某个时间点 | ① 默认经常**没开**；② 粒度粗（一天几次 / 每小时），**救不了"刚才那 3 秒"**；③ 不知道"是谁干的、谁批的"；④ 目录外无效 | 免费或订阅 |
| **③ 反删除 / 数据恢复** | **Windows**：Recuva、DiskGenius、EaseUS、R-Studio、GetDataBack、PhotoRec/TestDisk、微软 Windows File Recovery · **Mac**：Disk Drill、Prosoft Data Rescue、Stellar、R-Studio、PhotoRec | 磁盘上**还没被覆盖**的删除块 | ① **SSD 开了 TRIM 基本没戏**（Win10/11 默认开，很多机器 24h 内物理擦除）；② **覆盖写/编辑**没有残片；③ 捞回来是 `$RFxxxx.tmp`，**不知道版本、来源、时间**；④ 要求"立刻停写"，和 agent 正在干活冲突 | 一次性 ¥100–800 |
| **④ agent 级撤销 / 隔离**（**最相关**） | **Claude Code `/rewind`**（v2.0，2025-09-29；每轮快照、100 个、约 30 天）· **Cursor**（Restore Checkpoint）· **Cline / Roo Code**（shadow git）· **Zed**（agent + checkpoint）· **Aider**（git 自动提交 + `/undo`）· **Conductor**（mac，本地免费 / Pro \$50 / Teams \$60·人·月）· **Nimbalyst（Crystal 继任者） / Superset / Parallel Code / Claude Squad**（worktree 隔离，开源/免费）· Warp | 它**自己那套文件编辑工具**的改动 | ① **Claude 官方明说：Bash 的 `rm/mv/cp` 回不来**；② 桌面/GUI 操作完全不管；③ **restore 本身常常不可逆**（Cursor / Zed 社区 issue 都承认"没法撤销这次 restore"）；④ 不落审计、没有审批归属；⑤ 换一个 agent 就用不了 | 免费为主 |
| **④-b Windows 原生 ADE / 多 agent 工作台**（**2026-11 新增，必须单列**） | **AgentMux**（Win 主平台 / Microsoft Store / Apache 2.0 / 19 harness / Drone DAG / Audit / Vault / Agent 间通信）· **Nimbalyst**（Crystal 继任者 / MIT / Win·mac·Linux / worktree + 阶段 Kanban + session chaining）· **Volt**（MIT / Win·mac·Linux / VS Code 内核 / ACP 原生 / 每轮 git checkpoint）· **Kepler**（GitKraken / Win·mac·Linux / Agent Graph / worktree）· **AionUi**（Apache 2.0 / Win·mac·Linux / ACP 多 agent / Team Mode / cron） | 并行会话、worktree 隔离、可视化编排、审批、日志 | ① **隔离几乎都建在 git 上**；② 审计多为"日志 / 图"，**公开文档未见哈希链 + 离线复核 + 签名**；③ 破坏性 shell 命令**删除前复制**未见等价能力；④ 非 git 目录的文件级回滚普遍缺失 | 免费 / 开源为主，团队版另收费 |
| 旁支 | Rewind / Limitless | 记录屏幕与音频 → "记忆/回放" | **不能撤销文件**，只是能回看 | 订阅 |

**结论（2026-11 复核）**：① ② 是"系统能力"，③ 是"事后捞残片"，④ 是"单 agent 自家撤销"，**④-b 是"多 agent 工作台"——Windows 上已经很多，不是空位**。
**仍然空着的是"操作层安全"这一格**：**不挑目录**（有无 git 均可）的删除前隔离 + 文件级回滚 + **哈希链审计** + 跨厂商 fail-closed 权限。
竞品大多把隔离建在 git worktree / checkpoint 上，审计停留在日志与可视化 —— 这一格才是我们的位置。

## 3. 三个硬限制：为什么"恢复软件"补不上 agent 的洞

1. **SSD + TRIM：删除即擦。** Win10/11 默认开启 TRIM，删除后底层块很快被 GC 物理擦除
   （实测口径：不少机器 24 小时内常规手段已无法恢复）。你不可能让客户"先关 TRIM、停掉一切写入、
   再跑恢复"来救一次 agent 误删 —— 而他当时正在让 agent 干活。
2. **覆盖写没有残片。** agent 改文件不是删除，是覆盖：旧内容在磁盘上直接被新内容盖掉，
   反删除软件没有任何东西可捞（**只有快照 / 版本仓有旧内容**）。
3. **没有归属。** 恢复出来的是一堆数据块，不是"`impl` 在 14:12、因为你说'清理旧报表'、张工批过、
   动了 21 个文件"这条事实链。**合规和问责要的是后者。**

> **我们的做法绕开了全部三条**：破坏性操作**放行前**复制进隔离区（`runtime/quarantine/`）+ 每轮
> 内容寻址快照（`runtime/snapshots/_store/`）→ 不依赖残片、不怕覆盖、每步都进哈希链。
> 一句销售话术：**恢复软件在赌运气，我们提前留了底。**

| 类别 | 具体 |
| --- | --- |
| 系统自带 | Time Machine（每小时）、APFS 本地快照（每小时，保 24h）、Versions（仅支持 NSDocument 的 App）、iCloud 版本历史 |

| **agent 编排 / 撤销** | **AgentMux**（Win/mac/Linux，Apache 2.0）、**Nimbalyst**（Crystal 继任者，MIT，Win/mac/Linux）、**Volt**（MIT，Win/mac/Linux）、**Kepler**（GitKraken，Win/mac/Linux）、**AionUi**（Apache 2.0）、**Conductor**（mac 独占，免费本地 + 付费云/多人）、**Superset**、**Parallel Code**、**Claude Squad**（tmux）、Vibe Kanban（社区维护）、Sculptor（容器）、Cursor / Cline / Zed / Aider / Warp（各自内建 checkpoint） |
| 云 SaaS 版本史 | Google Drive、Notion、Figma（**Figma 的 AI agent 没有 undo** —— 社区在问） |

**判断（2026-11 复核）**：**Mac 与 Windows 都已拥挤**，且主流免费 / 开源。
→ **不要再把"平台空位"当卖点**；空位在"操作层安全"：不挑目录、删除前隔离、可验证审计。

## 5. 三个演示（恢复软件与 checkpoint 都做不到）

1. **「撤销这一轮」**：只回 agent 这 3 步，**不动**我自己刚改的两个文件。
2. **「回到 14:12 那个点」并证明**：`impl` 在 `run_x` 里干的、张工批的、21 个文件、42 秒恢复 ——
   每行都带 `seq`，可回原始链复核（`cocraft_audit_verify.py`）。
3. **桌面 / GUI 动作**（点了删除、发了邮件、提交了表单）：**明确标"不可恢复"**，而不是假装能救。

## 7. 客户常见问题速答

**Q：Windows 不是有很多恢复软件吗？**
A：那些是"删完之后去捞残片"，而且 SSD 开了 TRIM 常常捞不回来。我们**在删之前就复制**了，
所以不赌运气；另外我们能说清"是谁、什么时候、谁批的"。

**Q：回收站不就行？**
A：命令行删除（`del` / `Remove-Item` / agent 用的那条）**不进回收站**。改文件也不进。

**Q：Claude Code 不是自带 /rewind 吗？**
A：自带，但它**只覆盖 Claude 自己的文件编辑工具**；官方文档写明 **Bash 的 `rm/mv/cp` 回不来**，
桌面/GUI 操作更不管。而且它只有 100 个快照 / 约 30 天，且不落审计链。

**Q：那你们和 git 有什么区别？**
A：git 管代码、要提交；我们管**整个工作目录 + 桌面动作**，不需要提交，还能回答"谁批的"。

**Q：能保证 100% 恢复吗？**
A：不能，也不该这么说。我们保证的是：**能识别的目标先隔离**、**改过的文件有快照**、
**恢复失败会如实告诉你"没保住"**（绝不假装成功）。⚠ 对外宣传别说"绝对安全 / 一定可撤回"。

**Q：发出去的邮件能撤回吗？**
A：不能，永久不能。我们做的是**在发之前拦下来问你**，并把这类动作用红字标"不可恢复"。
