## 关键设计与踩过的坑（本轮）

1. **主题必须是"底盘 + 叠加"**：`chapel` 走 `[data-theme]`（不是主题包），用户主题仍走 `data-theme-user`；切内置主题时先清叠加。
2. **`html.glass` 的 specificity 高于 `[data-theme]`** → 玻璃参数要写 `html.glass[data-theme="chapel"]`，否则被覆盖。
3. **气泡 / 全屏蒙层要看"底色亮不亮"**：38% 暖黑压不住白袍 → 气泡单独加厚、`.lb-wash` 换暗纱。**新增暗色主题必须自己换掉那张纸白纱**。
4. **`#topbar .actions button`（带 id）会盖掉 `.danger` 的红** → 危险键要单独一条规则（安全语义优先）。
5. **不要用运行时 `appendChild` 搬 DOM 当"分层"**：必须在正确时机执行，漏了就露出旧结构（`0.2.52`/`0.2.53`）。**直接写静态 HTML**。
6. **每轮改完前端必须 bump `?v=`**：`0.2.54` 改了 JS 却没 bump → 面板按旧 `?v=` 加载完不会再重载，用户看到的还是旧首屏。
7. **跨引擎"接续会话"要确认归属**：只有 `opencode-acp` 与 OpenCode 共用历史库；别的 agent 硬接只会留空壳（`0.2.59`）。
8. **别拿"文本里出现过某个词"当判据**（老坑复述）；`NOT:` 断言是防止旧文案/旧机制复活的唯一可靠手段。
9. **改大文档（`AGENTS.md`）别用"就地 replace + 拼字符串"的脚本**：本轮曾把文档重复/截断一次（已修复并核对了行数与各节唯一性）。改用 `edit` 精确片段 + 改完核对锚点。
